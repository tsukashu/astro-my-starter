# src ディレクトリ構造

## ツリー構造

```
src/
├── components/           # Astroコンポーネント
│   ├── Footer.astro      # フッターコンポーネント
│   ├── Header.astro      # ヘッダーコンポーネント
│   └── Main.astro        # メインコンポーネント
├── layouts/              # レイアウト
│   └── Layout.astro      # 基本レイアウト
├── pages/                # ページ
│   └── index.astro       # トップページ
└── styles/               # スタイルシート
    ├── _base.scss        # 基本スタイル
    ├── _mixins.scss      # ミックスイン
    ├── _reset.scss       # リセットスタイル
    ├── _variables.scss   # 変数定義
    └── styles.scss       # メインスタイル(SCSSのエントリーポイント)
```
